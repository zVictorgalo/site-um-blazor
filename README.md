# SiteUmBlazor

Lista de exercícios de Desenvolvimento Web (.NET 10 / Blazor).

| Página    | Rota        | Foco                         |
|-----------|-------------|------------------------------|
| Sobre     | `/sobre`    | `@page`                      |
| Contador  | `/contador` | `@code` e `@onclick`         |
| Mensagem  | `/mensagem` | Estado booleano e `@if`      |
| Placar    | `/placar`   | Múltiplos eventos de clique  |

## Executar

```
dotnet watch
```

Acesse `http://localhost:5100/sobre` (ou a porta exibida no terminal).

## Enviar para o GitHub (repositório `site-um-blazor`)

git init
